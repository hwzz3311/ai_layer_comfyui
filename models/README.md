# Local Models

Put the ModelScope RMBG-2.0 files here:

```text
/root/ComfyUI/models/RMBG-2.0
```

The `VR_HFMattingAlpha` node uses that directory as its default `model_id`.

Example ModelScope CLI command:

```bash
modelscope download --model briaai/RMBG-2.0 --local_dir /root/ComfyUI/models/RMBG-2.0
```
